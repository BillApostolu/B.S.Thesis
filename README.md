# Bachelor of Science Thesis

Welcome to the repository for my B.S. Thesis. This repository contains the final thesis document and abstract in Rnglish and Greek alongside the scripts utilised for this thesis and some examples of results.

## Important Note: Viewing the Thesis PDF
The main thesis PDF is a very large file. GitHub's built in web viewer will likely time out or fail to load it. 
Please do not wait for the web preview to render. Click on the PDF file in the repository, and click the **"Download raw file"** button to read it locally on your computer.

## Repository Structure
* **`ThesisBillApostolou.pdf`**: The complete B.S. Thesis.*
* **`.zip with generated images`**: Results examples.*
* **`CODE EXAMPLES.md`**: Codes inside the GEE environment where a Google Earth Engine account is needed to view the maps*
